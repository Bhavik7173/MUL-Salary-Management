# MUL Salary and Work-Hours Management Platform

A comprehensive application for work entries, payroll calculations, allowances, leave, analytics, spreadsheet imports, and professional payslips.

## Highlights

- Salary and time calculations
- Vacation and sick-day tracking
- Analytics and yearly summaries
- PDF, email, CSV, and Excel workflows

## Technology stack

React, FastAPI, MongoDB, ReportLab, Pandas, OpenPyXL
